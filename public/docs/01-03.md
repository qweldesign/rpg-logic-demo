#### 技能とは

技能とは、冒険を行う上で役に立つ、人物の心得ている様々な経験・知識のことです。  
それぞれの技能には、より多くのCPを消費することで、その腕前・技量を表す「技能値」を上昇させることができます。  
技能値は、消費CPと、技能に関連する能力値によって決まります (下記表) 。

以後、技能は「」付きで表記し、それをその技能の技能値を示すものとします。例えば「武術」と表記した場合、「武術」の技能値を示します。「武術」判定と表記した場合、「武術」の技能値で判定を行う、という意味になります。

近接戦闘を行う場合、通常はST(筋力)を基準とする「武術」と、DX(敏捷力)を基準とする「剣術」かどちらかを選択できます。装備や加ダメージを重視したい場合は「武術」、回避率を重視したい場合は「剣術」がお薦めです。  
なお、敵と戦うための主たる技能の技能値は、13は欲しいところです。

###### 表: 技能値と消費CP

| 消費CP | 技能値          |
| ---- | ------------ |
| 0CP  | 基準能力値 (技能無し) |
| 1CP  | 基準能力値+1      |
| 2CP  | 基準能力値+2      |
| 4CP  | 基準能力値+3      |
| 8CP  | 基準能力値+4      |

###### 表: 技能一覧

| 技能   | 基準 | 説明                      |
| ---- | -- | ----------------------- |
| 武術   | ST | 重装備で近接戦闘を行うための技能。       |
| 怪力   | ST | 加ダメージ量の算出に影響する技能。       |
| 剣術   | DX | 軽装備で近接戦闘を行うための技能。       |
| 運動   | DX | 回避判定の目標値の算出に影響する技能。     |
| 青の魔法 | IN | 回復・防御・補助などを行う魔法を扱える技能。  |
| 赤の魔法 | IN | 炎や雷を操り攻撃・補助を行う魔法を扱える技能。  |
| 緑の魔法 | IN | 風や木を操り攻撃・防御を行う魔法を扱える技能。 |
| 鍛錬   | HT | Hp (耐久値) の算出に影響する技能。   |

#### 戦闘能力値の算出

能力値と技能が決定したら、以下の戦闘に関係する値を算出しておいてください。

###### 表: 戦闘能力値の算出式

| 戦闘能力値        | 算出式                             |
| ------------ | ------------------------------- |
| Dmg (ダメージ修正) | ST (筋力) または「怪力」 / 2 (端数切捨) - 5  |
| EV (よけ)      | DX (敏捷力) または「運動」 / 2 (端数切捨) + 5 |
| Hp (耐久値)     | HT (生命力) または「鍛錬」 × 2 - 10       |
