#### 技能とは

技能とは、冒険を行う上で役に立つ、人物の心得ている様々な経験・知識のことです。  
それぞれの技能には、より多くのCPを消費することで、その腕前・技量を表す「技能値」を上昇させることができます。  
技能値は、消費CPと、技能に関連する能力値によって決まります (下記表) 。

以後、技能は「」付きで表記し、それをその技能の技能値を示すものとします。例えば「武術」と表記した場合、「武術」の技能値を示します。「武術」判定と表記した場合、「武術」の技能値で判定を行う、という意味になります。

近接戦闘を行う場合、通常はST(筋力)を基準とする「武術」と、DX(敏捷力)を基準とする「剣術」かどちらかを選択できます。装備や加ダメージを重視したい場合は「武術」、回避率を重視したい場合は「剣術」がお薦めです。  
なお、敵と戦うための主たる技能の技能値は、13は欲しいところです。

技能は冒険が始まってからミッションを達成したときに得られるCP (経験値) によって成長させるのが普通ですから、キャラクター作成時には能力値の確保を優先しましょう。

###### 表: 技能値と消費CP

| 消費CP      | 技能値           |
| --------- | ------------- |
| 0CP       | 基準能力値-2(技能無し) |
| 1/2CP     | 基準能力値-1       |
| 1CP       | 基準能力値         |
| 2CP       | 基準能力値+1       |
| 4CP       | 基準能力値+2       |
| 8CP       | 基準能力値+3       |
| 以後+8CPごとに | +1            |

#### 戦闘能力値の算出

能力値と技能が決定したら、以下の戦闘に関係する値を算出しておいてください。

###### 表: 戦闘能力値の算出式

| 戦闘能力値        | 算出式                                    |
| ------------ | -------------------------------------- |
| Dmg (ダメージ修正) | { ST (筋力) - 2 または「怪力」 } / 2 (端数切捨) - 5 |
| Ev (よけ)      | { DX (敏捷力) -2 または「運動」 } / 2 (端数切捨) + 5 |
| Hp (耐久値)     | { HT (生命力) -2 または「鍛錬」 } × 2            |
