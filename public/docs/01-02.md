#### CP

プレイヤーの分身となる人物 (PC) の作成は、持ち点 (CP:キャラクターポイント) を `10` 点とし、それを **ST (筋力)**、**DX (敏捷力)**、**IN (知力)**、**HT (生命力)** の4つの「能力値」、および技能に振り分けることから始めます。  
技能にもCPを使うので、`1〜4` 点ほど残しておいてください。

#### 能力値

能力値の初期値はどれも `10` ですが、値を大きくするほど必要な点数も等比数列的に増えていきますので、能力値の説明と、能力値と消費CPについては、下記表を参考にしてください。

###### 表: 能力値の説明

| 能力値     | 説明                     |
| ------- | ---------------------- |
| ST(筋力)  | 力の強さ。選べる装備や、加ダメージにに影響。 |
| DX(敏捷力) | 器用さ・素早さ。命中判定・回避判定に影響。  |
| IN(知力)  | 知恵・知識。魔法の発動判定・抵抗判定に影響。 |
| HT(生命力) | 根性。窮地に陥ったときの回復判定に影響。   |

###### 表: 能力値と消費CP

| 能力値 | 消費CP |
| --- | ---- |
| 10  | 0CP  |
| 11  | 1CP  |
| 12  | 2CP  |
| 13  | 4CP  |
| 14  | 8CP  |
